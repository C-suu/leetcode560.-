# leetcode560. 和为 K 的子数组：给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。子数组是数组中元素的连续非空序列。

---

# （0）纯人话讲解思路（完全不写代码）

## 一、题目到底在干什么？

题目给出：

* 一个整数数组 `nums`（一排数字）
* 一个整数 `k`

目标是：

> 数一数：**有多少段“连续的数字”加起来，刚好等于 k**

注意三点：

1. **子数组必须连续**
2. 子数组可以从任何位置开始
3. 子数组长度 ≥ 1

---

## 二、为什么“直接数”不行？

假设数组长度是 20,000。

如果每个位置都尝试：

* 从这里开始
* 一直往后加
* 看能不能凑成 k

那么计算次数大约是：

```
20000 × 20000 = 4 亿次
```

普通计算机会 **超时直接死掉**。

---

## 三、换一种“算账思路”

### 1️⃣ 引入一个“记账本”：前缀和

定义一个概念：

> **前缀和 = 从数组第一个数开始，一直加到当前位置的总和**

例如：

```
nums = [1, 2, 3]
```

| 位置 | 前缀和       |
| -- | --------- |
| 1  | 1         |
| 2  | 1+2 = 3   |
| 3  | 1+2+3 = 6 |

---

### 2️⃣ 子数组和 = 两个前缀和的差

假设：

* 前缀和到位置 j 是 `S_j`
* 前缀和到位置 i-1 是 `S_(i-1)`

那么：

```
从 i 到 j 的子数组和
= S_j - S_(i-1)
```

如果要让这段和等于 k：

```
S_j - S_(i-1) = k
```

变形得到：

```
S_(i-1) = S_j - k
```

**重点来了：**

> 当算到当前位置的前缀和是 `S_j`
> 只要之前出现过 `S_j - k`
> 那么就一定存在一个子数组，和为 k

---

## 四、如何快速知道“之前有没有出现过某个前缀和”？

使用一个**计数表（字典）**：

* 键：某个前缀和的值
* 值：这个前缀和出现过多少次

这个表的含义是：

> “历史上，出现过多少次这样的前缀和”

---

## 五、整个逻辑一句话总结

> 一边往前走，一边算前缀和
> 每到一个位置，就看看：
>
> * 之前出现过多少次 `当前前缀和 - k`
> * 每出现一次，就找到一个合法子数组

---

# （1）Python3 标准答案（每行都有中文注释）

```python
def subarraySum(nums, k):                     # 定义函数，输入是数组 nums 和目标值 k
    count = 0                                 # 用来记录“和为 k 的子数组数量”
    prefix_sum = 0                            # 当前已经累加到的前缀和
    prefix_count = {0: 1}                     # 记录前缀和出现次数，0 出现 1 次（表示什么都不取）

    for num in nums:                          # 从左到右，依次取出数组中的每一个数
        prefix_sum += num                     # 更新当前的前缀和
        need = prefix_sum - k                 # 计算“需要的历史前缀和”
        if need in prefix_count:              # 如果这个前缀和以前出现过
            count += prefix_count[need]       # 累加出现次数，等于新增子数组数量
        prefix_count[prefix_sum] = prefix_count.get(prefix_sum, 0) + 1
                                                # 更新当前前缀和出现次数

    return count                              # 返回最终统计结果
```

# （2）逐字逐句、逐符号解释代码（极度详细）

以下解释 **假设完全不知道：变量、循环、字典、函数**

---

### 第一行

```python
def subarraySum(nums, k):
```

* `def`：告诉计算机“现在要定义一个功能”
* `subarraySum`：这个功能的名字
* `nums`：第一个输入，代表“一排数字”
* `k`：第二个输入，代表“目标和”
* `:`：表示“下面的内容属于这个功能”

---

### 第二行

```python
count = 0
```

* `count`：一个名字，用来装“结果”
* `=`：赋值符号，把右边的值放进左边
* `0`：初始没有找到任何符合条件的子数组

含义：

> 目前为止，找到的答案数量是 0

---

### 第三行

```python
prefix_sum = 0
```

* `prefix_sum`：表示“当前已经加起来的总和”
* 初始为 0，表示“还没开始加任何数字”

---

### 第四行

```python
prefix_count = {0: 1}
```

这是最关键的一行之一。

* `{}`：表示一个“对照表”
* `0: 1` 的意思是：

  * 前缀和是 0
  * 出现过 1 次

含义：

> 在任何数字都没加之前，前缀和是 0，出现 1 次

这是为了处理“从第一个数开始就等于 k”的情况。

---

### 第五行

```python
for num in nums:
```

含义：

> 从左到右，一个一个取出 nums 里的数字
> 每次取出来的数字，叫做 num

---

### 第六行

```python
prefix_sum += num
```

等价于：

```
prefix_sum = prefix_sum + num
```

含义：

> 把当前数字加到前缀和里

---

### 第七行

```python
need = prefix_sum - k
```

含义：

> 如果以前出现过一个前缀和 = need
> 那么从那个位置之后到现在，加起来一定等于 k

---

### 第八行

```python
if need in prefix_count:
```

* `if`：条件判断
* `in`：表示“是否存在于”
* 判断：以前有没有出现过这个 `need`

---

### 第九行

```python
count += prefix_count[need]
```

含义：

> 如果 need 出现过 n 次
> 那么就新增 n 个符合条件的子数组

---

### 第十行

```python
prefix_count[prefix_sum] = prefix_count.get(prefix_sum, 0) + 1
```

分解来看：

* `prefix_count.get(prefix_sum, 0)`

  * 如果这个前缀和存在 → 取出次数
  * 如果不存在 → 当作 0
* `+ 1`：当前前缀和又出现了一次
* 整体：更新“前缀和出现次数”

---

### 最后一行

```python
return count
```

含义：

> 把统计好的答案交出去

# （3）完整数值算例 + 表格（一步不省）

示例：

```
nums = [1, 1, 1]
k = 2
```

初始状态：

```
count = 0
prefix_sum = 0
prefix_count = {0: 1}
```

---

| 步骤 | 当前 num | prefix_sum | need = prefix_sum - k | prefix_count  | 新增子数组 | count |
| -- | ------ | ---------- | --------------------- | ------------- | ----- | ----- |

| 3  | 1      | 3          | 1                     | {0:1,1:1,2:1} | 1     | 2     |

最终结果：`2`

# （6）背诵法则（考试 / 面试直接套）

### 一句话版

> 一边算前缀和，一边查历史前缀和减 k 出现了多少次

---

### 四步背诵版

1️⃣ 定义前缀和
2️⃣ 用字典记录前缀和出现次数
3️⃣ 每一步检查 `prefix_sum - k`
4️⃣ 累加出现次数

---

### 代码骨架背诵

```python
prefix_sum = 0
prefix_count = {0:1}
for num in nums:
    prefix_sum += num
    count += prefix_count.get(prefix_sum - k, 0)
    prefix_count[prefix_sum] += 1
```
